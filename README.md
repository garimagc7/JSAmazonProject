# Amazon Clone

A responsive Amazon-inspired e-commerce website built using HTML, CSS, and JavaScript.

This project was created as a frontend development project to practice building a real-world e-commerce interface, managing products, handling a shopping cart, and creating a checkout system.

## Features

- Amazon-inspired homepage
- Responsive navigation bar
- Product search interface
- Product category sections
- Product slider
- Product listing page
- Product filtering sidebar UI
- Product quantity selection
- Add to Cart functionality
- Shopping cart quantity counter
- Checkout page
- Order summary
- Shipping options
- Dynamic shipping cost calculation
- 10% tax calculation
- Delivery date selection
- Cart data stored using Local Storage
- Delete products from cart
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript
- ES6 Modules
- Local Storage
- Git & GitHub

## How it works

After opening the website click on the must-have for every students product grid it will direct to product page and click on the addToCart logo for adding to cart functionality.
